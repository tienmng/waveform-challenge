**HR cross-check:**
```python
def hr_from_beats(n_beats, seg_len=SEG_SAMPLES, fs=FS):
    return n_beats * 60.0 / (seg_len / fs)

def hr_crosscheck(n_ecg, n_ppg, n_abp, thr=QC_THRESHOLDS):
    hrs = dict(ecg=hr_from_beats(n_ecg), ppg=hr_from_beats(n_ppg), abp=hr_from_beats(n_abp))
    m = {f"hr_{k}": v for k, v in hrs.items()}
    valid = [v for v in hrs.values() if v > 0]
    if len(valid) >= 2:
        spread = max(valid) - min(valid)
        m["hr_spread_bpm"] = float(spread)
        m["flag_hr_disagree"] = bool(spread > thr["hr_abs_tol_bpm"])
    else:
        m["hr_spread_bpm"] = float("nan"); m["flag_hr_disagree"] = False
    return m
```
Wired into `segment_qc`; `flag_hr_disagree` added to both keep decisions.

*Notes:* absolute HR tolerance (15 bpm) — switch to relative if false positives at extreme rates;
recommended running report-only first.
