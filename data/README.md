# data/ — raw waveforms (NOT submitted)

This folder is where the downloaded MIMIC-III Blood Pressure waveform files go, and where the
notebook reads them from for Parts 1–2. Per the challenge, the raw waveform data is **left
out** of the submission, so you won't find the signal files here.

**Where to get it:** Harvard Dataverse — doi:10.7910/DVN/DBM1NF
`https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/DBM1NF`

**To reproduce the analysis:** accept the dataset's terms of use, download the waveform files
into this folder, then run the notebook.
